# 이순신 장군과 판옥선 — 3D 역사 체험

두 개의 GLB 모델을 Three.js로 함께 보여주는 실습입니다.

## 구성
- `index.html`: 3D 뷰어 및 장군 위치·크기 조절 기능
- `Sketchfab_panokseon.glb`: 판옥선 3D 모델
- `admiral-yi-sunsin.glb`: 이순신 장군 3D 모델

## 실행
네 파일을 GitHub 공개 저장소 최상위에 올리고 Settings → Pages → Deploy from a branch → main / (root) → Save를 선택합니다. 배포 URL로 접속합니다.

## 조작
화면 드래그로 회전, 휠/핀치로 확대합니다. 슬라이더로 장군의 좌우·높이·앞뒤·크기·회전을 조정하고 `설정값 복사`를 누르면 좌표를 복사할 수 있습니다. 초기 좌표는 임시값이므로 실제 지휘소 위치에 맞춰 조정해야 합니다.

모델은 SF3D에서 단일 이미지로 생성한 추정 형상으로, 역사적 고증을 보장하지 않습니다.
